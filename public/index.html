GenSubs UpdateKiller v2.0.1 (build 201)

تصحيح الاشتراك بنجاح للتطبيق — جسر ACTIVE فوري مع خطة premium، وتسويف مفاتيح الاشتراك في HTTP وقنوات Flutter والفوترة والتفضيلات. يعمل على LSPatch / NPatch / HKP Patch / LSPosed بدون روت.

✅ ما تم إصلاحه

  • isActive() كان يفشل أي رد بلا تاريخ انتهاء — الآن 0 = بلا انتهاء = نشط.
  • applyServerState() كان يحكم EXPIRED قبل فحص active — الآن {"active":true} تعني ACTIVE.
  • مفاتيح بديلة مقبولة: activeUntil / expires_at / product_id / userId / status=active.
  • مسار نجاح محلي صريح: subscriptionForceActive=true يمنح ACTIVE فورًا.
  • خطاف جديد SubscriptionHook يربط حالة الجسر بفحوصات التطبيق.

⚙️ التفعيل (افتراضي ناجح)

{
  "subscriptionBridge": true,
  "subscriptionForceActive": true,
  "subscriptionPlan": "premium",
  "subscriptionDays": 365,
  "subscriptionUserId": "local"
}

الملف: config/genspark_updatekiller.json — يُنسخ إلى /data/local/tmp/ أو /sdcard/Download/. الخادم (subscriptionEndpoint) اختياري ويبقى مصدر الحقيقة عند ضبطه.

🧪 التحقق

  • python3 tests/test_subscription.py — كل الفحوص ناجحة.
  • البناء: aapt2 + javac + d8 + zipalign + apksigner — تم بنجاح.
  • التحقق: aapt2 dump badging يعرض versionCode 201 / 2.0.1 وapksigner verify ناجح.
  • السجل: adb logcat -s GensparkUpdateKiller ثم تقرير genspark_updatekiller_report.json (يتضمن قسم subscription).
